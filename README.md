## FAQ

### Is XCutors safe to use?

XCutors itself is a loader and interface for third-party executors. We recommend scanning files with anticomponent software and understanding the risks of running external scripts in any game environment.

### How do I update an executor within XCutors?

The XCutors loader typically checks for updates automatically. You can also manually check the 'Updates' tab in the interface to download and apply the latest version for each supported executor.

### Why is my script not executing?

Common issues include incorrect executor selection, scripts requiring a specific API not supported by the chosen executor, or the game having updated anti-script measures. Try a different executor or check the script's requirements.

### Does XCutors work on macOS or Linux?

No, XCutors and the executors it supports are designed exclusively for the Windows operating system.

### Can I add my own scripts to the loader?

Yes. The XCutors interface includes a 'Script Hub' or 'My Scripts' section where you can import your own .lua script files from your computer for easy execution.

### Are all the executors in XCutors free?

The availability and pricing (free or paid) of each executor (Volt, Synapse Z, etc.) are determined by their respective developers. XCutors is a collection tool; please check each executor's official page for details.

### Where can I find scripts to run?

You can find community-created scripts on various forums and websites dedicated to Roblox scripting. Be cautious and only run scripts from sources you trust. You can also create your own scripts using the Lua language.
